# Vascular Injury

## Coagulation
### Hemostasis
- Injury → vasoconstriction
- Collagen & von Willebrand factor exposed
  - Platelet adhesion → via GPIb/IX receptor
  - Platelet activation → conformational change
  - Platelet aggregation → via GP IIb/IIIa receptor
  - → primary hemostatic plug
- D/t clotting factors → definitive clot
- Clot formation requires
  - Platelets
  - Clotting factors
  - Vascular endothelium

### Vasoconstriction
- Temporary stop in blood flow
- Mediators
  - Serotonin (from platelets)
  - Endothelin

### Coagulation cascade
- Positive feedback mechanism
- Intrinsic pathway (contact activation in labs)
  - Negatively charged surface + kininogen / kallikrein
  - XII → XIIa → XI → XIa → IX → IXa
  - VIII → VIIIa (by thrombin)
- Extrinsic pathway
  - Tissue injury → tissue factor (III)
  - VII → VIIa
- Common pathway
  - X → Xa (+ Va, Ca²⁺)
  - Prothrombin (II) → thrombin (IIa)
  - Fibrinogen (I) → fibrin (Ia)
  - XIII → XIIIa → stable fibrin clot

### Clotting factors
- I → fibrinogen
- II → prothrombin
- III → tissue thromboplastin
- IV → Ca²⁺
- V → proaccelerin
- VII → proconvertin
- VIII → anti-hemophilic factor A
- IX → anti-hemophilic factor B (Christmas factor)
- X → Stuart-Prower factor
- XI → anti-hemophilic factor C
- XII → Hageman factor
- XIII → fibrin stabilizing factor

### Applied aspect — deficiency
- Fibrinogen → afibrinogenemia
- Prothrombin → hypoprothrombinemia (2° to vitamin K deficiency)
- Proaccelerin → parahemophilia
- Proconvertin → hypoconvertinemia
- Anti-hemophilic factor A → hemophilia
- Anti-hemophilic factor B → Christmas disease
- Anti-hemophilic factor C → PTA deficiency
- Hageman factor → Hageman triad

### Coagulation profile
- APTT
  - Kaolin → XII → XIIa
  - Cephalin → substitute for platelet phospholipids
  - Ca²⁺
  - Assesses intrinsic & common pathway
  - Normal 26–40 s
  - Defect → VIII, IX, XI, XII, V, X, fibrinogen, prothrombin
- PT
  - Exogenous tissue thromboplastin + Ca²⁺
  - Assesses extrinsic & common pathway
  - Normal 11–16 s
  - Defect → VII, V, X, fibrinogen, prothrombin
- Platelet count → 1.5–4 lakh cells/mm³
- Bleeding time → 2–8 min
- Clotting time → 3–6 min

## Anticoagulation
### Anticoagulation pathways
- Thrombin + thrombomodulin
  - Activates protein C & protein S → inactivate V, VIII
  - Activates tPA → plasminogen → plasmin / fibrinolysin
- Antithrombin III + heparin
  - Inactivates IX, X, XI, XII
- Tissue factor pathway inhibitor (TPI)
- Thrombomodulin absent in cerebral circulation

### Factors regulating anticoagulation
- Plasminogen activator inhibitor
- α2-antiplasmin
- Thrombin activatable fibrinolysis inhibitor

### Role of vitamin K
- Glutamic acid → (vitamin K) → γ-carboxyglutamic acid
- Activates factors II, VII, IX, X
- Activates protein C & protein S
- Warfarin → inhibits the vitamin K step
