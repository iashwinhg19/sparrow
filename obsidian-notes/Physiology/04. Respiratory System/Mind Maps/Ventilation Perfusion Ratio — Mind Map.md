# Ventilation Perfusion Ratio

## Ventilation Perfusion Matching & Mismatch
### Ventilation perfusion matching
- V/Q = alveolar ventilation (V) ÷ pulmonary circulation (Q)
- Apex → V/Q 3.2 → highest
  - Large alveoli (against gravity)
  - ↓ compliance
  - ↓ exchange of gases
  - V ↓, Q ↓↓↓ → ratio ↑
- Middle → V/Q 0.8 → normal ratio
- Base → V/Q 0.6 → lowest
  - Small alveoli (towards gravity)
  - ↑ compliance
  - ↑ exchange of gases
  - V ↑, Q ↑↑↑ → ratio ↓
- Applied aspect
  - Apex has highest O2 (perfusion ↓↓)
  - → Mycobacterium tuberculosis infests apex (d/t ↑ O2)

### Ventilation perfusion mismatch
- Wasted ventilation
  - Q = 0 → V/Q = infinity
  - Physiological → anatomical dead space
  - Pathological → pulmonary embolism
- Wasted perfusion
  - V = 0 → V/Q = 0
  - Physiological → alveoli with no O2
  - Physiological → shunt blood (2 % of cardiac output)
  - Pathological → foreign body / tumour of airway
  - → collapse → no air

### Ventilation perfusion graph
- O2–CO2 diagram (PO2 on x, PCO2 on y)
- Point C → V/Q = 0 → shunt blood
- Point B → V/Q normal → alveolar air (100 / 40)
- Point A → V/Q = ∞ → anatomical dead space (150 / 0)
- Left shift / deviation
  - PO2 ↓, PCO2 ↑ → V/Q falls
- Right shift / deviation
  - PO2 ↑, PCO2 ↓ → V/Q rises
