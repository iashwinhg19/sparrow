# Limbic System and Hypothalamus

## Limbic system
### Limbic cortex
- AKA smell brain / rhinencephalon
- Rim of cortical tissue
- Oldest part in terms of evolution
- Functions → emotions, smell & memory
### Amygdala
- Window of limbic system
- Genesis / seat of emotions
- Emotions regulated by frontal cortex
### Structures in the figure
- Hypothalamus, thalamus, septum
- Olfactory bulb, amygdala
- Mammillary body, hippocampus
### Clinical aspect
- Bitemporal region / amygdala lesion → Klüver–Bucy syndrome
  - Visual agnosia → objects not recognised on sight
  - Hypermetamorphosis → compulsion to explore
  - Placidity → no fear / anger
  - Hyperorality / hyperphagia → indiscriminate eating
  - Hypersexuality
- Medial temporal lobe lesion → mesial temporal lobe epilepsy
  - Complex partial seizure
  - Uncinate fits → smell / taste hallucination
  - Déjà vu → unfamiliar seems familiar
  - Jamais vu → familiar seems unfamiliar
### Papez circuit
- Cingulate cortex → (cingulum) → entorhinal cortex
- Entorhinal cortex → hippocampus
- Hippocampus → (fornix) → mamillary bodies
- Mamillary bodies → (mammillothalamic tract) → anterior thalamic nucleus
- Anterior thalamic nucleus → cingulate cortex
- Connects memory & emotion

## Hypothalamus
### Nature
- Head ganglion of autonomic nervous system
### Nuclei in the figure
- Posterior, dorsomedial, ventromedial
- Paraventricular, anterior hypothalamic
- Medial & lateral pre-optic
- Suprachiasmatic, supraoptic, arcuate
- Mamillary body
### Circadian rhythm
- Master clock → suprachiasmatic nucleus (SCN)
- Synchronises 24-hour bodily functions
### Regulation of food intake
- Arcuate nucleus → integration centre
- α-MSH + CART → ventromedial nucleus (satiety) → ↓ food intake
- NPY + AgRP → lateral nucleus → orexin → ↑ food intake
### Regulation of body temperature
- Hot → anterior nucleus
  - Sweating, vasodilation
  - Thirst (osmoreceptor)
- Cold → posterior nucleus
  - Shivering, vasoconstriction
  - ↑ urinary frequency
### Sleep & wakefulness
- Awake → lateral nucleus (orexin)
- Awake → posterior nucleus (histamine)
- Sleep centre → ventrolateral pre-optic nucleus
### Role in memory
- Mammillary body
- Chronic alcoholism → mammillary degeneration → memory impaired
- Wernicke–Korsakoff syndrome
  - Confusion
  - Ataxia
  - Confabulation (honest lying)
### Endocrine functions
- Releasing hormones → anterior pituitary
  - CRH → ACTH → cortisol (negative feedback)
- Inhibiting hormone → dopamine (prolactin inhibiting factor)
  - Inhibits prolactin release from anterior pituitary
- Paraventricular nucleus → major oxytocin, minor ADH
- Supraoptic nucleus → major vasopressin (ADH), minor oxytocin
- Both stored & released in posterior pituitary
### Sham rage
- Healthy → cerebral cortex ⊖ dorsomedial nucleus → no sham rage
- Decortication (removal of cortex) → sham rage
- Mild touch → arching of back, hissing, biting
- Centre → dorsomedial nucleus
- Removal of hypothalamus → abolishes sham rage
