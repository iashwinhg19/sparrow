# Sensory Receptors

## Neurophysiology
- Sensory physiology
- Motor physiology
- Higher mental functions
- Ascending sensory pathway → afferents / inputs
- Descending motor pathway → efferents / outputs

## Sensory physiology
### Senses
- General / somatic senses → receptor skin
  - Touch, pain, temperature
- Special senses → receptor CNS (page)
  - Vision, hearing, smell, taste, balance
### Sensory pathway
- ① Receptor (sensor) → 1st order neuron
- ② Spinal cord → 2nd order neuron (spinothalamic)
- Brainstem
- ③ Thalamus → relay station, 3rd order neuron
- ④ Cerebral cortex → 4th order neuron (page)
### Classification of receptors
- Mechanoreceptors → touch receptor
- Nociceptors → pain receptor
- Thermoreceptors → hot & cold
- Proprioceptors → joint position
- Exteroceptors → skin, external stimuli
- Interoceptors → osmoreceptors
- Telereceptors → photoreceptors (distant light)
### Properties (MILD)
- Modality → specific sense activating a receptor
- Intensity ∝ AP frequency
  - Amplitude constant → all or none law
- Location
  - Receptive field → area activating the receptor
  - Receptor density → receptors per field
  - Two-point discrimination → minimum separable distance
  - Receptor density ∝ 1 / two-point discrimination
  - Best at lips, fingertips; poorest on back
- Duration → start to end of receptor response

## General senses
### Touch
- Location → skin
- 1st order neuron → Aβ (large, myelinated)
- Meissner's corpuscles
  - Superficial → lips, fingertips
  - Tap, low-frequency vibration 5–40 Hz
- Merkel cells
  - Superficial
  - Touch, edges & corners → Braille reading
  - Sustained pressure
- Pacinian corpuscles (largest)
  - Deep, encapsulated
  - Pressure, high-frequency vibration 50–500 Hz
- Ruffini's endings
  - Deep → joint capsule receptor
  - Skin stretch, vibrations
### Pain
- Receptors → free nerve endings of Aδ & C
- Aδ fibres (myelinated)
  - Fast / first / epicritic pain
  - Neospinothalamic → glutamate
- C fibres (unmyelinated)
  - Slow / second / protopathic pain
  - Paleospinothalamic → substance P
- Hyperalgesia (inflammation)
  - Algogens → prostaglandin, serotonin, substance P
  - Algogens → histamine, bradykinin (most potent)
  - FNE sensitisation → ↓ threshold → ↑ firing → pain
- Allodynia → non-nociceptive stimulus felt as pain
- Local anaesthetics (lignocaine)
  - Block voltage-gated Na⁺ channel at FNE → analgesia
- CIPS → congenital absence of voltage-gated Na⁺ channel
### Analgesia
- Endogenous opioid system
  - Acupuncture → PAG
  - → endorphins, enkephalins, dynorphins → pain relief
- Stress-induced system
  - Fire walking → PAG (stress)
  - → endocannabinoids (anandamide) → pain relief
- Massaging & TENS → gate control theory
  - Non-painful sensations override painful ones
  - Aδ/C (+) → projection neuron (substantia gelatinosa)
  - Projection neuron → sensory cortex → pain
  - Aβ touch (+) → inhibitory interneuron (−) → projection neuron
### Visceral pain
- Unpleasant, poorly localised, referred
- Nausea, vomiting, sweating
- Conveyed via C fibres
- Pain sensitive → liver capsule, parietal pleura
- Pain insensitive → alveoli
### Temperature
- Thermoreceptors → free nerve endings in skin
- Cold receptors ≫ warm receptors
- Cold
  - Aδ & C fibres, TRPM (menthol)
  - 10–24 °C; nociception < 5 °C
- Warm
  - C fibres, TRPV (vanilloid)
  - 30–45 °C; nociception > 45 °C
- Normal body temperature → TRPV3
### Adaptation of receptors
- Rapidly adapting (RARs) → phasic
  - Fire at start & end only
  - Meissner's & Pacinian corpuscles
- Slowly adapting (SARs) → tonic
  - Fire throughout the stimulus
  - Merkel cells, Ruffini's endings, free nerve endings
