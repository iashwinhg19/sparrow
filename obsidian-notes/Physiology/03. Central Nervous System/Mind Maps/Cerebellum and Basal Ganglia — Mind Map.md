# Cerebellum and Basal Ganglia

## Cerebellum
### Function
- Timing & coordination of motor movement
### Histology
- External molecular layer
  - Basket cell
  - Stellate cell (star shape)
- Purkinje cell layer
  - Purkinje cell → largest cell in cerebellum
  - Receives climbing fibre input
- Inner granular layer
  - Granule cell
  - Golgi cell
- Inhibitory cells → GABA
  - Basket, stellate, Purkinje, Golgi
- Excitatory cell → glutamate
  - Granule cell only
### Deep nuclei
- Mnemonic D, E, F, G (lateral → medial)
- 1 Dentate → largest nucleus
- 2 Emboliform + 4 Globose → interpositus nucleus
- 3 Fastigial → most medial
### Gross anatomy
- Vermis + intermediate zone → spinocerebellum
- Lateral hemisphere → neocerebellum
- Nodulus + flocculus → flocculonodular lobe (vestibulocerebellum)
### Physiology
- Sensory input → cerebellum → motor output
- Start pathway
  - Inferior olive → climbing fibres ⊕ deep cerebellar nuclei
  - → ⊕ brainstem & thalamus → ⊕ cerebral cortex → movement starts
  - Eg: archer pulls the string
- Stop pathway
  - Inferior olive → climbing fibres ⊕ Purkinje cells
  - Purkinje ⊖ deep cerebellar nuclei → movement stops
  - Eg: archer releases fingers (DCN inhibited)
- Pre-start pathway
  - Spinal cord → mossy fibres
  - Dorsal SCT → inferior cerebellar peduncle
  - Ventral SCT → superior cerebellar peduncle
  - → granule cells → parallel fibres
  - ⊕ basket, stellate → ⊖ Purkinje → DCN inhibition lost
  - ⊕ Golgi cells → ⊖ granule cells (feedback inhibition)
  - → new movement can start
  - Eg: archer pulls the string again
### Functions
- Spinocerebellum → emboliform, fastigial, globose
  - Coordination of motor movements
- Vestibulocerebellum → vestibular nuclei
  - Equilibrium / balance
  - Regulating eye movements
- Neocerebellum (recently evolved) → dentate
  - Planning motor movements
- Vestibular apparatus helps balance with the cerebellum
### Signs of cerebellar lesions
- Truncal ataxia
- Wide based stance
- Titubation → tremor of head
- Ataxic / drunken gait
- Nystagmus
- Decomposition of movement → breakdown into parts
- Past pointing → finger–nose test
- Intention (kinetic) tremor → with activity, absent at rest
- Dysarthria → scanning speech
- Pendular knee jerk
- Dysdiadochokinesia → cannot alternate supination–pronation
- Rebound phenomenon → cannot stop the movement

## Basal ganglia
### Nuclei
- Caudate + putamen → striatum (input nuclei)
- Globus pallidus
  - Interna → output nucleus
  - Externa
- Substantia nigra
  - Pars reticulata → output nucleus
  - Pars compacta → dopamine
- GP and SN → inhibitory
- Subthalamic nucleus → excitatory
- Neurotransmitter colours
  - Orange → GABA
  - Green → dopamine
  - Blue → glutamate
### Physiology
- Planning of motor movements
- Cognition (caudate nucleus)
- Inhibition of voluntary & involuntary movements (even at rest)
- Lesions → involuntary movements
### Neural pathway
- Cortex → GLU ⊕ striatum
- Direct pathway → facilitates movement
  - SN → DA ⊕ via D1
  - Striatum → GABA ⊖ GP interna
  - GP interna's inhibition of thalamus lost
  - → movement
- Indirect pathway → inhibits movement
  - SN → DA ⊖ via D2
  - Striatum → GABA ⊖ GP externa
  - GP externa's inhibition of subthalamic nuclei lost
  - Subthalamic → GLU ⊕ GP interna
  - GP interna → GABA ⊖ thalamus → no movement
- Thalamus (ventral anterior) → GLU ⊕ cortex
- Dopamine facilitates direct & indirect pathway
### Parkinsonism
- Pathology → ↓ dopamine in SN pars compacta
- Bradykinesia → paucity of movements
- Pill-rolling tremors → resting tremors
- Medical → L-DOPA crosses BBB
  - Ineffective over time → progressive loss of DA neurons
  - Dopamine can't cross BBB
- Surgical
  - Stereotactic ablation → thalamus VA & VL nuclei → alleviates symptoms
  - Deep brain stimulation → subthalamic nucleus → improves movements
### Huntington's disease
- Normal gene → neuroprotective, anti-apoptotic, BDNF
- Mutation → CAG trinucleotide repeat
  - → ↑ polyglutamine → excitotoxicity
  - → loss of GABA cells of caudate (striatum)
  - → ↑ involuntary movements (chorea)
- Chorea → dance-like involuntary movements
- Memory abnormality → cognition affected
### Involuntary movements
- Chorea → dance like → caudate nucleus
- Athetosis → slow writhing (snake charmer) → globus pallidus
- Hemiballismus → violent flinging of one large joint → subthalamic nucleus
