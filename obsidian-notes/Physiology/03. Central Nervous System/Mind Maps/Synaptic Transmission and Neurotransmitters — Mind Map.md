# Synaptic Transmission and Neurotransmitters

## Synaptic transmission
### Types
- Electrical mode
  - Gap junctions (connexin protein)
  - Fast mode
- Chemical mode (neurotransmitters)
  - Mediated by chemicals (eg: ACh at motor endplate)
  - Slow mode
### Structure
- Presynaptic neuron → stored NT
- Synaptic cleft
- Postsynaptic neuron → NT receptors
- Release of NT → NT receptor binding
  - → postsynaptic / end plate potential (local)
  - → summation → crosses threshold → AP
- Types of synapse
  - Axon – axon
  - Axon – somatic
  - Axon – dendritic
### Post synaptic potentials
- Fast EPSP
  - Na⁺ and Ca²⁺ in
  - Glutamate, acetylcholine
- Slow EPSP
  - ↓ K⁺ efflux
  - Autonomic ganglia, cardiac, smooth muscle
  - Latency 500 ms
- Fast IPSP
  - Cl⁻ in, K⁺ out
  - GABA
- Slow IPSP
  - ↑ K⁺ efflux
  - Latency 500 ms
### Regulation
- Facilitation
  - Presynaptic Ca²⁺ channel open for long
  - → ↑↑↑ Ca²⁺ → ↑ NT release
- Postsynaptic inhibition
  - GABA-mediated inhibition
- Presynaptic inhibition
  - Via (−) interneuron
  - AKA lateral inhibition (retina)
- Feedback inhibition
  - Renshaw cell (α motor interneuron)
  - Inhibits α motor neuron through glycine

## Neurotransmitters
### Basics
- First NT discovered → acetylcholine
- Criteria
  - Synthesised & stored in presynaptic neuron
  - Released into synapse
  - Acts on postsynaptic receptor
- Classes
  - I → acetylcholine
  - II → biogenic amines (DA, NE, 5-HT)
  - III → amino acids (glutamate, GABA, glycine)
  - IV → gases (NO, CO)
### Class I acetylcholine
- Release → exocytosis by SNAREs + Ca²⁺
  - SNAP-25, syntaxin → membrane
  - Synaptobrevin → vesicle
  - Synaptotagmin → Ca²⁺ sensor
- Botulinum toxin degrades SNAREs
  - → no ACh release → flaccid paralysis
- Receptors
  - Nicotinic → ion channel, ionotropic, fast
  - Muscarinic → GPCR, metabotropic, slow
- Location & function
  - NMJ → muscle contraction
  - Nucleus basalis of Meynert → ↓ in Alzheimer's
  - REM-on neurons → sleep
  - Sweat glands → sympathetic cholinergic
### Class II biogenic amines
- Norepinephrine
  - Synthesised from dopamine
  - Locus coeruleus → wakefulness
  - Widespread brain activation → arousal
- Dopamine pathways
  - Nigrostriatal → basal ganglia (substantia nigra)
  - Nigrostriatal → motor movement; ↓ → Parkinson's bradykinesia
  - Mesolimbic → VTA, nucleus accumbens
  - Mesolimbic → reward, addiction
  - Mesocortical → prefrontal cortex
  - Mesocortical → motivation, emotion, decisions, memory
  - Tuberoinfundibular → hypothalamus to pituitary
  - Tuberoinfundibular → inhibits prolactin
- Dopamine receptors
  - D1–D5 → all GPCR
- Serotonin sources
  - Brain (raphe) → awake state
  - GIT → regulate peristalsis
  - Platelets → aggregation
- Serotonin receptors (5-HT1 to 5-HT7)
  - 5-HT2a → platelet aggregation
  - 5-HT2c → GIT, ↓ food intake (satiety)
  - 5-HT4 → GIT peristalsis
  - 5-HT6,7 → limbic system
  - 5-HT3 → ionotropic, area postrema → vomiting
- Histamine
  - Posterior hypothalamus → wakefulness
  - Parietal cell → ↑ HCl
### Class III amino acids
- Glutamate → major excitatory NT
  - Hippocampus, subthalamic nucleus → memory
  - A-delta fibres → fast pain
  - AMPA → Na⁺ in → depolarisation
  - Depolarisation removes Mg²⁺ block of NMDA
  - Glycine + glutamate → activate NMDA
  - Excitotoxicity → ↑ Ca²⁺ → cell death (ALS)
  - Rx → riluzole
  - Subthalamic nucleus → only excitatory BG nucleus
- GABA → major inhibitory NT
  - Basal ganglia → caudate & putamen (striatum)
  - Inhibits involuntary movements
  - Acts in hyperpolarisation phase
  - Loss in striatum → Huntington's chorea
- Glycine
  - Both excitatory & inhibitory
  - α motor neuron → Renshaw feedback inhibition
  - Strychnine → glycine blocked
  - Tetanospasmin → GABA release blocked
  - Both → spastic paralysis, sustained contraction
### Class IV gases
- Nitric oxide
  - Source → arginine
  - Location → hippocampus
  - Needs cGMP; ↑ presynaptic glutamate release
  - Learning and memory
- Carbon monoxide
  - Heme → heme oxygenase 2 → CO
  - Olfaction, pain transmission, memory
