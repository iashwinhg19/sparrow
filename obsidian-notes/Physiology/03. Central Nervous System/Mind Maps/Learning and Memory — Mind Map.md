# Learning and Memory

## Cerebral hemispheres
### Left
- Old name → dominant hemisphere
  - 96 % of right-handed
  - 70 % of left-handed
- New name → categorical hemisphere
- Functions → language, speech, learning & memory
- Thinking → logic based
- Lesions → aphasias, dyscalculias
### Right
- Old name → non-dominant hemisphere
- New name → representational hemisphere
- Functions → visuospatial representation, creativity, musical ability
- Thinking → intuition based
- Lesions → astereognosis, agnosia, hemispatial neglect

## Memory
### Memory engram
- Collection of memories
### Based on awareness
- Explicit / declarative (expressive)
  - Semantic → facts & places
  - Episodic → events
  - Stored → hippocampus, medial temporal lobe
- Implicit / non-declarative (subconscious)
  - Procedural (skills) → striatum
  - Priming → neocortex
  - Conditioning → amygdala, cerebellum
### Based on time
- Short term → minutes to seconds, requires attention
  - Immediate → eg 100 − 7 test (5 sequences)
  - Working → eg phone numbers
- Long term → weeks to months
### Synaptic plasticity
- Modification of strength of synaptic transmission
- Based on activity
- Potentiation
  - Post-tetanic potentiation
  - Long term potentiation (LTP)
  - Sensitization
- Depression
  - Long term depression (LTD)
  - Habituation
### Long term potentiation
- Occurs in hippocampus / cornu ammonis / Ammon's horn
- Short-term memory → consolidation / LTP → long-term memory
- CA1 neurons → memory neurons
- Pathway
  - Sensory inputs → perforant pathway → entorhinal cortex
  - Direct → entorhinal → CA1
  - Indirect → dentate → CA3 → Schaffer collateral → CA1
- Mechanism → Hebb's rule
  - Repeated activation → synaptic strengthening
  - Pre-synaptic → glutamate + nitric oxide
  - AMPA receptor (Na⁺) → depolarisation
  - Depolarisation → removes Mg²⁺ block of NMDA
  - NMDA (Ca²⁺ channel) → Ca²⁺ second messenger
  - Ca²⁺ → produces proteins → synaptic strengthening
- Applied → hippocampal lesion → anterograde amnesia
  - Cannot form new long-term memories
  - Intact → recent, short term, procedural, past
### Long term depression
- Occurs in cerebellum
- Faulty synapses depressed → correct connections established
### Other areas
- Mamillary bodies → recollective memory
  - Degeneration → Wernicke–Korsakoff psychosis (alcoholics)
- Thalamus anterior nucleus → recent memories
- Nucleus basalis of Meynert → acetylcholine
  - Degeneration → Alzheimer's disease
- Amygdala → memory with emotions
- Entorhinal cortex → memory with smell
- Corpus callosum → hemispheric transfer of memory

## Speech
### Broca's area
- Inferior frontal cortex, Brodmann 44
- Motor speech area → output, expression, word formation
- Lesion → non-fluent aphasia
  - Speech output ↓, repetition impaired
### Wernicke's area
- Superior temporal gyrus, Brodmann 22
- Sensory speech area → understanding, comprehension
- Lesion → fluent aphasia
  - Speech output ↑, comprehension lost
### Arcuate fasciculus
- Connects Broca's & Wernicke's areas
- Lesion → conduction aphasia
### Angular gyrus
- Brodmann 39
- Integrates vision & speech
- Lesion → anomic aphasia (cannot name a seen object)
