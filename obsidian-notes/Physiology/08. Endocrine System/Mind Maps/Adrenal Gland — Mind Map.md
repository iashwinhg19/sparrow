# Adrenal Gland

## Anatomy
### Gross anatomy
- Sits on the superior surface of the kidney
- Cortex 78 %
- Medulla 22 %
### Histopathology (outside → in)
- Connective tissue capsule
- Zona glomerulosa
  - Aldosterone (mineralocorticoid)
  - Stem cells → regeneration of cortical cells
- Zona fasciculata (50 %)
  - Cortisol (glucocorticoid)
- Zona reticularis
  - Adrenal sex steroids
- Medulla → catecholamines
  - Epinephrine
  - Norepinephrine
  - Dopamine

## Physiology
### Steroid hormone synthesis
- Cholesterol = precursor
  - Desmolase → pregnenolone
- Zona glomerulosa column
  - Pregnenolone → 3β HSD → progesterone
  - → 21-hydroxylase → 11-deoxycorticosterone (weak mineralocorticoid)
  - → 11-β hydroxylase → corticosterone (weak glucocorticoid)
  - → aldosterone synthetase → aldosterone
- Zona fasciculata column
  - 17-α hydroxylase → 17-OH pregnenolone / 17-OH progesterone
  - 3β HSD links the two 17-OH steps
  - → 21-hydroxylase → 11-deoxycortisol
  - → 11-β hydroxylase → cortisol
- Zona reticularis column
  - 17,20 lyase → dehydroepiandrosterone (DHEA)
  - DHEA source → adrenal cortex 90 %, ovary 10 %
  - Sulfotransferase → DHEAS (exclusively adrenal cortex)
  - 3β HSD → androstenedione
  - Peripheral tissues → testosterone
  - Aromatase → estrogen
- Enzyme deficiency → congenital adrenal hyperplasia
- Major source of testosterone → testis
### Regulation — HPA axis
- Hypothalamus → CRH
- Anterior pituitary → ACTH
- Adrenal cortex → cortisol, aldosterone, sex steroids
- Cortisol → negative feedback on hypothalamus and pituitary
- Adrenal medulla → NOT under ACTH control

## Adrenocortical hormones
### Aldosterone
- Steroid hormone, life saving
- 60 % bound to binding proteins
- t½ 20 min
- Principal cell (collecting duct)
  - Inactive MR → active form → proteins
  - ENaC → Na⁺ in (H₂O follows)
  - ROMK → K⁺ out to lumen
  - Na⁺–K⁺ ATPase on blood side
  - Spironolactone ⊣ MR
  - Amiloride ⊣ ENaC
- Type A intercalated cell
  - CO₂ + H₂O → H₂CO₃ → H⁺ + HCO₃⁻
  - H⁺ ATPase and H⁺–K⁺ ATPase → H⁺ out
  - Aldosterone (+) H⁺–K⁺ ATPase
  - Cl⁻–HCO₃⁻ exchanger → HCO₃⁻ to blood
- MR sites
  - Kidneys, colon, hippocampus
  - Salivary glands, sweat glands
- Regulators
  - Hyperkalemia → stimulates release
  - ACTH → ↑ aldosterone transiently
### Hyperaldosteronism
- Conn's syndrome
  - Aldosterone producing adrenal adenoma
  - Metabolic alkalosis
  - Hypokalemia → cramps, interstitial atony, nephropathy
  - Na⁺ & H₂O retention → ↑ ECF → ↑ BP, no edema
- Aldosterone escape
  - Pressure diuresis (↑ BP) + ANP natriuresis
  - → Na⁺ & H₂O excretion despite ↑ aldosterone → no edema
- Glucocorticoid remediable hyperaldosteronism
  - Aldosterone synthase + 11β-hydroxylase → hybrid enzyme
  - ↑ ACTH → sustained aldosterone release
  - Treatment → dexamethasone (inhibits ACTH)
### Hypoaldosteronism
- Addison's disease (adrenal insufficiency)
  - Hyponatremia
  - Postural hypotension
  - Hyperkalemia
  - Microcardia
### Cortisol
- 90–95 % bound to CBG / transcortin
- t½ 60–90 min
- GR mechanism
  - Inactive GR + cortisol → active GR (cytoplasm)
  - → nucleus → binds DNA
### Cortisol functions vs Cushing's syndrome
- Protein → proteolysis → alanine (catabolic); liver protein synthesis (anabolic)
  - Cushing's → muscle weakness, proximal (steroid) myopathy
- Carbohydrate → gluconeogenesis → hyperglycemia
  - Cushing's → glucose intolerance, adrenal diabetes
- Lipid → lipolysis → ↑ free fatty acids
  - Cushing's → dyslipidemia, buffalo hump, moon face
- Immune → universal anti-inflammatory
  - Inhibits leukotrienes, phospholipase A₂
  - Cushing's → ↑ infections
- Blood cells → ↓ eosinophils, basophils, lymphocytes
  - ↑ RBCs, neutrophils, platelets
  - Cushing's → eosinopenia, hypercoagulable state
- Nervous → ↑ appetite, weight gain, mood
  - Cushing's → irritability, psychosis
- Heart → ↑ cardiac output, ↑ vascular tone
  - Cushing's → hypertension, atherosclerosis
- Kidney → ↑ GFR, ↑ Ca²⁺ excretion
  - Cushing's → hypercalciuria → renal stones
- Bone & connective tissue
  - Inhibits fibroblast proliferation, collagen formation
  - Promotes bone resorption
  - Cushing's → thin skin, ecchymosis, striae, osteoporosis
- GIT → ↑ gastric acid
  - Cushing's → peptic ulcer
- Reproduction → inhibits GnRH
  - Cushing's → amenorrhea, loss of libido, infertility
- Catecholamines + cortisol → enhanced lipolysis, bronchodilation
### Other cortisol diseases
- Addison's → cortisol deficiency
  - Hypoglycemia, fatigue
  - Eosinophilia, lymphocytosis
- SAME
  - Normal → 11β-HSD2 inactivates cortisol → MR kept free
  - Cortisol has ↑ affinity to MR
  - Licorice → glycyrrhetinic acid ⊣ 11β-HSD2
  - → cortisol binds MR → apparent mineralocorticoid excess
### Sex steroids
- DHEA
- DHEAS → most circulating hormone in humans
- Androstenedione
- Testosterone (small amounts)
- Functions → axillary hair, pubic hair, libido
- ↑ adrenal androgens
  - Adrenocortical tumors
  - Congenital adrenal hyperplasia
  - Adrenogenital syndrome
- Adrenogenital syndrome features
  - Females (more severe) → pseudohermaphroditism
  - Beard, deep voice, baldness, hirsutism, clitoromegaly
  - Prepubertal males → rapid development of male sex organs
