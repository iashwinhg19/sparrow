# Cardiac and Smooth Muscles

## Cardiac muscle
### Properties
- Found in the heart
- Large nucleus
- Plenty of mitochondria → generate ATP
- Histology
  - Intercalated disc → gap junctions
  - Gap junction protein → connexins
- Striated muscle
- Involuntary → pacemaker SA node
- Regulatory proteins → troponin & tropomyosin
- Myosin heavy chain
  - α-MHC → atrium
  - β-MHC → ventricles
### Functional syncytium
- Specific to cardiac muscle
- Gap junction → rapid impulse transmission
  - → all cells contract & relax together
  - → large force to pump out blood
### Titin in cardiac muscle
- Elasticity → ability to recoil
- Titin mutation → dilated cardiomyopathy (DCM)
  - Muscles stretch without recoil
  - → dilated cardiac chambers
### Length–tension relationship
- Blood enters in diastole → EDV
- EDV stretches chambers → change in length
- Tension → force of contraction
### Frank–Starling law
- Force of contraction ∝ initial fibre length
  - Within physiological limits
- Pressure–volume curve
  - Rises with EDV → plateau
  - Over-stretch → fall in pressure
### Ca²⁺ induced Ca²⁺ release
- AP → extracellular Ca²⁺ influx
- → SR Ca²⁺ release through RyR
- → contraction
- iCa²⁺ back to SR by SERCA → relaxation
### Diad vs triad
- Cardiac → 1 T tubule + 1 SR → diad
- Skeletal → 1 T tubule + 2 SR → triad
### Phospholamban and norepinephrine
- Phospholamban ⊣ SERCA
- NE ⊣ phospholamban (phosphorylation)
  - → ↑ Ca²⁺ storage
- Enhances relaxation → +ve lusitropy
- Adequate Ca²⁺ for next beat → +ve inotropy
### Absence of tetanisation
- Evolutionary adaptation → cannot be tetanised
- Long ARP → no summation → no tetany

## Smooth muscle
### Properties
- Classical location → GIT
- Hallmark → absence of striations
- Involuntary
- Pacemaker → Cajal cells
- Dense bodies → functional Z lines
- Ca²⁺ binding protein → calmodulin
- Inelastic → no titin
### Types of smooth muscle
- Single unit
  - Unitary, gap junctions +
  - Uterus, urinary bladder, ureter, GIT
- Multiunit
  - Individual subunits, no gap junctions
  - Vascular smooth muscle (blood vessel)
### Control of smooth muscles
- No well-defined NMJ
- Regulated by autonomic nervous system
- Varicosities
  - Enlarged nerve endings
  - Acetylcholine → parasympathetic
  - Norepinephrine → sympathetic
- Synapse en passant
  - One nerve fibre → many smooth muscle cells
### Contraction & relaxation
- Parasympathetic → ↑ Ca²⁺ → contraction
- Source of Ca²⁺
  - Extracellular
  - Intracellular → RyR, IP₃ receptor
- Contraction
  - Ca²⁺ + calmodulin → MLCK
  - → activates myosin → myosin actin overlap
- Relaxation → MLCP
- Rho kinase ⊣ MLCP → inhibits relaxation
- Fasudil ⊣ Rho kinase → MLCP + → relaxation
- Sympathetic → inhibits MLCK → no contraction
### Unique features
- Plasticity
  - No titin → stretch without recoil
  - Uterus stretches as fetus grows
  - Bladder stretches to store urine
- Latch bridge phenomenon
  - Energy efficiency
  - Sustained contraction with low ATP
  - GIT sustained contraction for digestion
