# ⚖️ Homeostasis

> [!abstract] Core Definition
> Homeostasis[^ety-homeostasis][^pre-homeo][^suf-stasis] is the **concept of constancy**[^ety-constancy][^pre-con] — the **central theme for bodily function**. Every system in physiology exists to keep the internal environment within a narrow range, and
> - ✅ **Disturbance in homeostasis → disease**
> - ✅ The body keeps it constant with **three control systems**: negative feedback, positive feedback and feedforward

---

## 🧠 Mental Model — A Thermostat, an Avalanche and a Weather Forecast

Think of the three control systems by what they do to an error:

```
NEGATIVE FEEDBACK   = THERMOSTAT   → error appears → system OPPOSES it      → back to normal   (stabilising, 99 % of control)
POSITIVE FEEDBACK   = AVALANCHE    → error appears → system AMPLIFIES it    → runs to an end   (destabilising: CLAPS)
FEEDFORWARD         = FORECAST     → NO error yet  → system ANTICIPATES it  → error prevented  (exercise, braking, shell temp)
```

## 🔁 Control Systems of Homeostasis

Mechanisms of the body to maintain homeostasis = **control systems**:

```
                        CONTROL SYSTEMS
          ┌──────────────────┼──────────────────┐
  Negative feedback   Positive feedback     Feed forward
```

### ➖ Negative feedback[^ety-feedback]

> [!info] ↑ in stimulus[^ety-stimulus] → ↓ parameters[^ety-parameter]
> The response is **opposite** in direction to the stimulus: ↑ stimulus → ↓ response (and ↓ stimulus → ↑ response).

**Eg:**
1. **Baroreflex**[^ety-baroreflex][^pre-baro] — changes in BP: ↑ during exercise, ↓ after exercise; the reflex pulls it back each time.
2. **Endocrine hormone regulation (99 %)**[^ety-endocrine][^pre-endo] — almost every hormone switches off its own release.
3. **Gastric acid secretion** — acid in the stomach inhibits further acid release.[^1]

![Negative feedback loop — stimulus, sensor, control centre, effector (OpenStax)](https://upload.wikimedia.org/wikipedia/commons/thumb/2/22/105_Negative_Feedback_Loops.jpg/800px-105_Negative_Feedback_Loops.jpg)
*The four parts of every negative feedback loop — stimulus → sensor (receptor) → control centre → effector — shown with body temperature (OpenStax Anatomy & Physiology, CC BY 4.0).*

#### Components of –ve feedback — the baroreflex worked through

| Component | In the baroreflex |
|---|---|
| **Stimulus** | ↑ BP |
| **Acts on receptors**[^ety-receptor][^pre-re] | **Baroreceptors** |
| **Afferents**[^ety-afferent][^pre-ad] | Afferent nerves (to the centre) |
| **Centre** | **Medulla**[^ety-medulla] |
| **Efferents**[^pre-ex] | **SNS (–)** and **PNS (+)** → **↓ HR & ↓ BP** |
| **Response** | BP back towards normal |

- **SNS** — sympathetic[^ety-sympathetic][^pre-syn] nervous system (inhibited).
- **PNS** — parasympathetic[^pre-para] nervous system (stimulated).

#### Assessment of effectiveness of –ve feedback — **Gain**[^ety-gain]

```latex
\text{Gain } (G) = \frac{\text{Correction by the system } (C)}{\text{Error remaining } (E)}
```

**Infinite feedback gain:** when the error becomes zero → G = C / 0 = **∞** → **Gain = infinity**.[^2]

**Eg:**
- **Kidneys always correct blood pressure back to normal** (the renal–body fluid mechanism has infinite gain).
- In **HTN**[^ety-hypertension][^pre-hyper] → **kidneys are affected** → **BP never comes back to normal**.

![[Homeostasis - kidneys correct blood pressure.png]]
*Kidneys always bring blood pressure back to normal — the example of infinite feedback gain; in hypertension the kidney is affected and BP stays high (cropped from the handwritten page).*

### ➕ Positive feedback

> [!warning] ↑ in initiating stimulus → **further ↑ in response**
> - **Amplification / cascade**[^ety-cascade] of reactions.
> - AKA **vicious cycle**[^ety-vicious] — **destabilizes** our system.

**Eg: CLAPS (mnemonic)**

| Letter | Example | How the loop amplifies |
|---|---|---|
| **C** | **Coagulation**[^ety-coagulation][^suf-ation] cascade | Each activated clotting factor activates more of the next → thrombin activates its own upstream factors |
| **L** | **LH**[^ety-lh] **surge** | **Only exception for true (positive) feedback in endocrine hormone regulation**[^3] |
| **A** | **Action potential** | Depolarisation opens Na⁺ channels → more Na⁺ in → more depolarisation |
| **P** | **Parturition**[^ety-parturition] (normal delivery) — AKA **Ferguson reflex**[^ety-ferguson] | See the loop below |
| **S** | **Shock** | Haemorrhagic shock (eg: RTA) → irreversible shock → death (+ve feedback) |

**Parturition — the Ferguson reflex loop:** the fetal head stretches the uterine cervix[^ety-cervix], which reflexly releases oxytocin[^ety-oxytocin]; oxytocin makes the uterus contract, which pushes the head down harder on the cervix — and round it goes.

```
Fetal head
   ↓
Pressure on uterine cervix  ◄──────────┐
   ↓                                   │  cycle
Oxytocin release                       │
   ↓                                   │
Uterine contraction                    │
   ↓                                   │
Pushes fetal head further down ────────┘
   ⇒ eventually leads to delivery of fetus
```

![Positive feedback in childbirth — stretch of the cervix → oxytocin → stronger contractions (Wikimedia Commons)](https://upload.wikimedia.org/wikipedia/commons/thumb/0/0e/Positive_Feedback-_Childbirth_(1).svg/800px-Positive_Feedback-_Childbirth_(1).svg.png)
*Positive feedback in labour: the loop keeps amplifying until the baby is delivered and the stimulus (cervical stretch) disappears (Wikimedia Commons).*

**Shock:** **Haemorrhagic**[^ety-haemorrhagic][^suf-rrhage] **shock**[^ety-shock] (eg: **RTA**) → **irreversible shock** → **death** (+ve feedback).[^4]

### ⏩ Feedforward control system

> [!tip] Core theme: **Anticipatory**[^ety-anticipatory][^pre-ante] **control system**
> The body responds **anticipating a stimulus** — **no actual stimulus** yet.

**Eg:**

a) **Anticipatory tachycardia**[^ety-tachycardia][^pre-tachy][^suf-cardia] **& tachypnea**[^ety-tachypnea][^suf-pnoea]: ↑ RR and ↑ HR **before exercise**.

b) **Anticipatory motor control**:
- **Centre: Cerebellum**[^ety-cerebellum][^suf-ellum]
- Person driving on a highway → applies brakes on seeing a cow (**anticipates danger**).

c) **Anticipatory regulation of core body temperature**[^ety-temperature]:
- Skin temperature → **shell temperature**.
- Body organ temperature → **core temperature**.
- The hypothalamus[^ety-hypothalamus][^pre-hypo] reads the fall in shell temperature and starts correcting **before** the core has cooled:

```
Cold environment
      ↓
↓ shell temperature
      ↓
Hypothalamus anticipates ↓ core temperature
      ↓
Corrective measures (vasoconstriction, shivering, heat-seeking behaviour)
      ↓
Maintenance of core temperature
```

*Shell temperature (skin) vs core temperature (organs) — the hypothalamus reads the shell to anticipate a fall in the core (cropped from the handwritten page).*

## 📏 Properties of Homeostasis

### Dynamic constancy[^ety-dynamic]
- AKA **dynamic equilibrium**[^ety-equilibrium][^pre-equi].
- Homeostatic control systems maintain a **"range of values"**, not one fixed value.
- **Eg:** Normal HR = **60–100 bpm**; Normal RR = **12–18 /min**.[^5]

![[Homeostasis - dynamic constancy tolerance range.png]]
*Static value vs dynamic constancy — the parameter oscillates between an upper and a lower limit (the tolerance range) (cropped from the handwritten page).*

### Prioritization of parameters
- **Priority of order of correction of parameters: pH > BP > Temperature.**
- **pH changes are given more priority** — as they **affect the activity of enzymes**[^ety-enzyme] → **death**.[^ety-ph]

## Core Dictum & Pattern Recognition

> [!check]+ **🎯 Core Dictum - The Unifying Principle**
>
> The body does not hold its internal environment at a single number; it holds it inside a **tolerance range**, and it does so with three tools chosen by what they do to an error. **Negative feedback opposes the error** and is the default for anything that must stay stable (BP, hormones, acid). **Positive feedback amplifies the error** and is used only when the body wants a process to run to completion (a clot, an action potential, a delivery, the LH surge) — anywhere else it is a vicious cycle that kills (shock). **Feedforward acts before the error exists**, using prediction (cerebellum, hypothalamus) so the correction is already under way.
>
> The quality of a negative feedback system is its **gain** (correction ÷ error left); the kidney's control of BP has infinite gain because it keeps working until the error is zero — which is why kidney disease is the root of sustained hypertension.

> [!example]+ **📊 Clinical Pattern Recognition**
>
> Understanding how the condition progresses through stages helps you recognize it at different phases and predict outcomes.
>
> **Stage 1 - Normal Physiology:**
> Each parameter oscillates inside its tolerance range (HR 60–100, RR 12–18). Negative feedback loops with high gain detect every deviation through receptors, compare it at a centre (medulla, hypothalamus, endocrine gland) and drive effectors to cancel it; feedforward loops start corrections before the disturbance arrives.
>
> **Stage 2 - Compensated/Early Pathology:**
> A disturbance pushes a parameter toward the edge of its range — blood loss lowers BP, cold lowers shell temperature. The negative feedback loops respond in proportion (baroreflex tachycardia and vasoconstriction, hypothalamic shivering), and because correction is still possible the patient may show only these compensatory signs. Parameters are defended in order of danger: pH first, then BP, then temperature.
>
> **Stage 3 - Decompensated/Overt Disease:**
> When the disturbance exceeds what negative feedback can correct, the loop's own effectors fail (ischaemic heart, failing kidney) and the system flips into positive feedback: poor perfusion weakens the heart, which lowers perfusion further. Haemorrhagic shock becomes irreversible and ends in death; a kidney that can no longer excrete salt leaves BP permanently high.
>
> **Progression Timeline:**
> Normal → disturbance (blood loss / cold / disease) → negative feedback compensation → effector failure → positive feedback "vicious cycle" → irreversible state / death
>
> **Why This Matters Clinically:**
> Treatment aims to restore the negative feedback before the positive one takes over — fluids and blood in haemorrhage, cooling or warming before the core temperature moves. Recognising positive feedback (a worsening that accelerates itself) is the signal to intervene urgently, because the body will not stop it on its own.

> [!warning]+ **🔍 Diagnostic Buzzwords & Pattern Recognition**
>
> These are the key terms, phrases, and clinical patterns that should immediately trigger specific diagnoses in your mind. When you see these in a clinical vignette or real patient, you should think of the associated condition instantly.
>
> **Buzzwords by Condition:**
>
> **Negative feedback:** "Response opposite to the stimulus", "baroreflex", "hormone inhibits its own release", "gastric acid secretion" → The loop exists to stabilise; almost all endocrine control (99 %) works this way.
>
> **Positive feedback:** "Amplification", "cascade", "vicious cycle", "CLAPS" → Coagulation, LH surge, Action potential, Parturition, Shock. Ask: does the process need to finish (clot, birth, spike)? Then positive feedback is normal; otherwise it is pathological.
>
> **Feedforward:** "Anticipatory", "before exercise", "no actual stimulus", "cerebellum", "shell temperature" → Anticipatory tachycardia/tachypnea, motor control, core-temperature regulation.
>
> **Infinite gain:** "Error becomes zero", "kidneys always bring BP back to normal" → renal–body fluid control of arterial pressure.
>
> **Ferguson reflex:** "Fetal head presses on the cervix → oxytocin → contraction" → positive feedback of parturition.
>
> **Visual/Imaging Buzzwords:**
> A wave oscillating between an upper and lower limit = dynamic constancy / tolerance range; a straight line = a static value the body does not actually keep.
>
> **Severity Indicators:**
> Order of defence: pH > BP > temperature. A disturbance that has moved pH is the most dangerous; haemorrhagic shock that has become irreversible marks the switch from negative to positive feedback.

> [!danger]+ **⚠️ Common Traps & Pitfalls**
>
> These are the mistakes that students and clinicians commonly make with this topic. Being aware of these traps helps you avoid diagnostic errors and answer tricky exam questions correctly.
>
> **Trap 1: "Homeostasis keeps every value fixed"**
>
> **What students think:** Homeostasis means a parameter stays at one exact number.
>
> **Why this is wrong:** Homeostasis is *dynamic constancy* (dynamic equilibrium): the value oscillates within a tolerance range — HR anywhere between 60 and 100 is normal. A fixed value would need infinite energy and infinite gain everywhere. The body defends a range and corrects only when a limit is crossed.
>
> **How to avoid this trap:** Picture the wave, not the line: "range of values" is the exam phrase.
>
> **Trap 2: Forgetting that positive feedback can be physiological**
>
> **What students think:** Positive feedback is always harmful.
>
> **Why this is wrong:** CLAPS lists four normal processes (coagulation, LH surge, action potential, parturition) and only one harmful one (shock). Positive feedback is safe whenever the loop has a natural end point — the clot plugs the hole, the baby is delivered, the Na⁺ channels inactivate.
>
> **How to avoid this trap:** Ask "does it have an off-switch built in?" — yes = physiological; no = vicious cycle.
>
> **Trap 3: Calling the LH surge negative feedback**
>
> **What students think:** All endocrine regulation is negative feedback.
>
> **Why this is wrong:** About 99 % is, but the mid-cycle LH surge is the classic exception: rising oestrogen from the dominant follicle, once high enough for long enough, *stimulates* LH release, which raises oestrogen further until ovulation.
>
> **How to avoid this trap:** "L in CLAPS = the only endocrine positive feedback."
>
> **Trap 4: Mixing up feedback and feedforward**
>
> **What students think:** Any rapid response before something happens is a fast negative feedback.
>
> **Why this is wrong:** Feedback needs an error that has already occurred; feedforward acts on a prediction with no actual stimulus yet. Tachycardia *before* starting to run, braking on *seeing* the cow and shivering when only the *skin* is cold are all feedforward.
>
> **How to avoid this trap:** Ask "has the controlled variable changed yet?" — no = feedforward.
>
> **Trap 5: Thinking the infinite-gain system can never fail**
>
> **What students think:** Because the kidney's gain is infinite, BP can never stay high.
>
> **Why this is wrong:** Infinite gain describes a healthy kidney that keeps excreting salt and water until the error is zero. When the kidney itself is diseased (the effector fails), the loop resets at a higher pressure and BP never comes back to normal — the mechanism of most sustained hypertension.
>
> **How to avoid this trap:** "Infinite gain needs a healthy effector."

## 🏆 Pearls (High-Yield Summary)

> [!success] Must-Know Pearls
> 1. Homeostasis = **concept of constancy**; disturbance → **disease**.
> 2. **Claude Bernard** → *milieu intérieur*; **Walter Cannon** → *homeostasis*.
> 3. Three control systems: **negative feedback, positive feedback, feedforward**.
> 4. Negative feedback: ↑ stimulus → ↓ parameter — **baroreflex, endocrine hormone regulation (99 %), gastric acid secretion**.
> 5. Baroreflex components: ↑ BP → **baroreceptors** → afferents → **medulla** → efferents (**SNS –, PNS +**) → ↓ HR & ↓ BP.
> 6. **Gain = Correction ÷ Error remaining**; error zero → **infinite gain** (kidneys and BP).
> 7. Positive feedback = **amplification / cascade / vicious cycle** — **CLAPS**: Coagulation, LH surge, Action potential, Parturition (**Ferguson reflex**), Shock.
> 8. **LH surge** = the only true positive feedback in endocrine regulation.
> 9. Feedforward = **anticipatory** control, no actual stimulus — exercise tachycardia/tachypnea, **cerebellum** (braking on seeing a cow), **hypothalamus** (shell → core temperature).
> 10. **Dynamic constancy** = dynamic equilibrium = a **range of values** (HR 60–100, RR 12–18).
> 11. Priority of correction: **pH > BP > Temperature** (pH affects enzymes → death).

## 🔁 One-Line Recall

```
CONSTANCY (Bernard: milieu intérieur · Cannon: homeostasis) → disturbance = disease
−VE FEEDBACK: oppose the error (baroreflex, 99 % hormones, gastric acid) · Gain = C / E → E = 0 → ∞ (kidney & BP)
+VE FEEDBACK: amplify the error — CLAPS (Coagulation · LH surge · Action potential · Parturition/Ferguson · Shock)
FEEDFORWARD: no stimulus yet — exercise HR/RR · cerebellum braking · hypothalamus shell → core
PROPERTIES: dynamic constancy (range, not a point) · priority pH > BP > Temp
```

[^1]: Gastric acid feedback: low antral pH stimulates D cells to release somatostatin, which inhibits gastrin and so further acid — the textbook example of negative feedback in the gut ([[Gastrointestinal Hormones]]).
[^2]: Guyton gives the baroreflex a gain of about −2 (it corrects two-thirds of a pressure change) and temperature control about −33; only the renal–body fluid mechanism for long-term arterial pressure approaches infinite gain, because it keeps excreting salt and water until the error is zero. The minus sign marks negative feedback.
[^3]: The LH surge: once oestradiol from the dominant follicle stays above ~200 pg/mL for ~2 days, it switches from inhibiting to stimulating GnRH/LH release — positive feedback that ends with ovulation. Oxytocin in labour is also positive feedback but neuro-endocrine (a reflex), which is why the notes single out the LH surge as "true" endocrine positive feedback.
[^4]: In progressive shock, low arterial pressure reduces coronary flow → the heart weakens → pressure falls further; tissue acidosis and capillary leak add further loops. Beyond a point no transfusion restores circulation — "irreversible shock".
[^5]: The notes give RR 12–18 per minute; many textbooks quote 12–20. The page's value is kept in the body.
[^ety-homeostasis]: **homeostasis** — Greek *homoios*, "similar, like" + *stasis*, "standing still" → staying similar; coined by Walter Cannon (1926) for a condition that *varies* but stays relatively constant — not *homo-*, "same", which would mean a fixed value. **Differentiate:** *homeostasis* (a regulated steady state that costs energy) vs *equilibrium* (no net flow and no energy needed — a dead cell reaches equilibrium).
[^ety-constancy]: **constancy** — Latin *con-*, "with, thoroughly" + *stare*, "to stand" → standing firm; the state of staying the same within limits.
[^ety-bernard]: **Claude Bernard** — French physiologist (1813–1878), founder of experimental medicine, who described the constancy of the *milieu intérieur* in the 1850s–1870s ("the stability of the internal environment is the condition for free and independent life").
[^ety-milieu]: **milieu intérieur** — French, "the inner middle / surroundings": *mi-* "middle" + *lieu* "place" + *intérieur* "inner" → the internal environment, i.e. the extracellular fluid that bathes every cell.
[^ety-cannon]: **Walter Bradford Cannon** — American physiologist at Harvard (1871–1945), who coined *homeostasis* in 1926 and popularised it in *The Wisdom of the Body* (1932); also described the "fight or flight" response.
[^ety-feedback]: **feedback** — English *feed* + *back*, from 1920s radio engineering: part of the output is fed back to the input. **Differentiate:** *negative* feedback (output opposes the input — stabilises) · *positive* feedback (output reinforces the input — amplifies) · *feedforward* (the controller acts on a predicted input before any output change).
[^ety-stimulus]: **stimulus** — Latin, "a goad, a pointed stick for driving cattle" → anything that prods a receptor into action; plural *stimuli*.
[^ety-parameter]: **parameter** — Greek *para-*, "beside" + *metron*, "measure" → a measuring line beside; in physiology a measurable regulated variable (BP, pH, temperature).
[^ety-baroreflex]: **baroreflex** — Greek *baros*, "weight, pressure" + Latin *reflexus*, "bent back" (*re-* "back" + *flectere* "to bend") → a pressure signal bent back as a response. *Baroreceptors* are stretch receptors in the carotid sinus and aortic arch.
[^ety-endocrine]: **endocrine** — Greek *endon*, "within" + *krinein*, "to separate, to secrete" → secreting into the blood (within); vs *exocrine* (*exō*, outside — into a duct) and *paracrine* (*para*, beside — to neighbouring cells).
[^ety-receptor]: **receptor** — Latin *recipere*, "to take back, to receive" (*re-* + *capere*) + *-tor*, the agent → the receiver of a stimulus.
[^ety-afferent]: **afferent / efferent** — Latin *ad-* (assimilated to *af-*), "towards" + *ferre*, "to carry" → carrying towards the centre; *ex-* (assimilated to *ef-*), "out of" + *ferre* → carrying away from it. **Memory:** **A**fferent **A**rrives, **E**fferent **E**xits.
[^ety-medulla]: **medulla** — Latin, "marrow, pith, innermost part" → the medulla oblongata (*oblongata*, "elongated") of the brainstem holds the cardiovascular and respiratory centres. Same word in *adrenal medulla* and *renal medulla* — the inner part of an organ.
[^ety-sympathetic]: **sympathetic / parasympathetic** — Greek *syn-* (*sym-* before *p*), "together" + *pathos*, "feeling" → feeling together (Galen thought organs "sympathised" through these nerves); *para-*, "beside" → the system beside the sympathetic (craniosacral outflow).
[^ety-gain]: **gain** — from control engineering: how strongly a system corrects an error, Gain = correction ÷ error remaining. Old Norse *gagn*, "advantage". **Differentiate:** gain −2 (baroreflex, corrects two-thirds), −33 (temperature), ∞ (renal control of BP).
[^ety-hypertension]: **hypertension** — Greek *hyper-*, "over, excessive" + Latin *tensio*, "stretching" (*tendere*, to stretch) → excessive stretching (pressure) in the arteries. Opposite *hypotension* (*hypo-*, under).
[^ety-cascade]: **cascade** — Italian *cascata*, "waterfall" (*cascare*, to fall) → each step falls onto and triggers the next, growing as it goes; the image behind the coagulation cascade.
[^ety-vicious]: **vicious cycle** — Latin *vitiosus*, "faulty" (*vitium*, a fault) + Greek *kyklos*, "circle" → a faulty circle where each step worsens the one before; Latin *circulus vitiosus*. Not related to *viscous* (sticky).
[^ety-coagulation]: **coagulation** — Latin *co-*, "together" + *agere*, "to drive" → *coagulare*, "to curdle, drive together" + *-ation*, the process → the process of driving blood into a solid clot. **Differentiate:** *coagulation* (fibrin clot formation) · *agglutination* (*ad-* + *gluten*, glue — cells clumping by antibodies) · *thrombosis* (a clot inside an intact vessel).
[^ety-lh]: **LH (luteinising hormone)** — Latin *luteus*, "yellow" → it forms and maintains the *corpus luteum* ("yellow body") after ovulation; *-izing*, "making into".
[^ety-parturition]: **parturition** — Latin *parturire*, "to be in labour" (from *parere*, to bring forth) + *-ition*, the process → the process of giving birth. Same root as *postpartum* and *parity*.
[^ety-ferguson]: **Ferguson reflex** — James Kenneth Wallace Ferguson, Canadian physiologist, who described in 1941 that stretching the cervix and vagina reflexly releases oxytocin.
[^ety-cervix]: **cervix** — Latin, "neck" → the neck of the uterus; *cervical* also means "of the neck" (cervical spine) — context decides.
[^ety-oxytocin]: **oxytocin** — Greek *oxys*, "swift, sharp" + *tokos*, "childbirth" → swift birth; named by Henry Dale (1906) for its effect on the uterus. Do not confuse with *oxytetracycline* (*oxy-* there means oxygen).
[^ety-haemorrhagic]: **haemorrhagic** — Greek *haima*, "blood" + *rhēgnynai*, "to burst forth" + *-ic* → caused by blood bursting out. *Haemorrhagic shock* = shock from blood loss.
[^ety-shock]: **shock** — French *choc*, "a violent blow" → circulatory collapse with inadequate tissue perfusion. Types: hypovolaemic (incl. haemorrhagic), cardiogenic, distributive (septic, anaphylactic, neurogenic), obstructive.
[^ety-anticipatory]: **anticipatory** — Latin *ante-*, "before" + *capere*, "to take" → taking (acting) beforehand. Watch the prefix: *ante-* (before) vs *anti-* (against) — *anti*cipate is "before", not "against".
[^ety-tachycardia]: **tachycardia** — Greek *tachys*, "swift" + *kardia*, "heart" + *-ia*, condition → fast heart rate (> 100/min). Opposite *bradycardia* (*bradys*, slow).
[^ety-tachypnea]: **tachypnoea** — Greek *tachys*, "swift" + *pnoē*, "breathing" → fast breathing. **Differentiate:** *tachypnoea* (fast) · *hyperpnoea* (deep, ↑ minute ventilation matching metabolism, as in exercise) · *hyperventilation* (ventilation beyond metabolic need → ↓ PaCO₂) · *dyspnoea* (the sensation of difficult breathing).
[^ety-cerebellum]: **cerebellum** — Latin, "little brain" (diminutive of *cerebrum*, brain) → the motor-coordination centre that predicts and corrects movement — the feedforward centre of this chapter.
[^ety-temperature]: **temperature** — Latin *temperare*, "to mix in due proportion, to moderate" → the "tempered" state of the body; *core* (Old French *cuer*, heart) vs *shell* (outer covering).
[^ety-hypothalamus]: **hypothalamus** — Greek *hypo-*, "below" + *thalamos*, "inner chamber" → the region below the thalamus; houses the thermostat, thirst, hunger and the pituitary controls.
[^ety-dynamic]: **dynamic** — Greek *dynamis*, "power, force" → in motion, changing; *dynamic constancy* = constant on average while always moving.
[^ety-equilibrium]: **equilibrium** — Latin *aequus*, "equal" + *libra*, "balance, scales" → equal balance. **Differentiate:** *dynamic equilibrium* in this chapter really means a regulated steady state; a true thermodynamic equilibrium needs no energy and exists only after death.
[^ety-enzyme]: **enzyme** — Greek *en*, "in" + *zymē*, "leaven, yeast" → "in yeast"; named by Wilhelm Kühne (1877). Enzymes are proteins whose shape (and so activity) depends on pH — the reason pH is corrected first.
[^ety-ph]: **pH** — "potential (power) of hydrogen", introduced by Søren Sørensen in 1909; *p* is usually read as German *Potenz* or French *puissance* (power) — origin disputed. pH = −log [H⁺]; normal 7.35–7.45.
[^pre-homeo]: **homeo- / homoeo-** — similar, like: homeostasis, homeotherm (keeps a similar body temperature). Don't confuse with **homo-** same, identical (homozygous, homologous) · **hetero-** other, different.
[^suf-stasis]: **-stasis** — standing still, stopping: homeostasis (staying similar), haemostasis (stopping blood), cholestasis (bile standing still). Don't confuse with *metastasis* (*meta-* + *stasis* = a change of place) · **-static** as an adjective (bacteriostatic — stops growth, vs **-cidal**, kills).
[^pre-con]: **con- / com- / co-** — together, with, thoroughly: constancy, coagulation, congenital. Don't confuse with **contra-** against (contraindication) · **counter-** against (countercurrent).
[^pre-baro]: **baro-** — weight, pressure: baroreceptor, baroreflex, barotrauma. Don't confuse with **brady-** slow · **bari-** heavy (bariatric — same root *baros*, used for body weight).
[^pre-endo]: **endo-** — within: endocrine, endothelium, endoscopy. Don't confuse with **exo-** outside (exocrine) · **ecto-** outer (ectoderm) · **para-** beside (paracrine).
[^pre-re]: **re-** — back, again: receptor (takes back), reflex (bent back), reabsorption. Don't confuse with **retro-** backwards, behind (retroperitoneal) · **pre-** before.
[^pre-ad]: **ad- (af-, ac-, ag- …)** — to, towards; the *d* turns into the next consonant: afferent, aggregation, accommodation. Don't confuse with **ab-** away from (abduction) · **a- / an-** without (anaemia).
[^pre-ex]: **ex- (ef-, e-)** — out of, away: efferent, effector, excretion. Don't confuse with **exo-** outside (Greek: exocrine) · **extra-** beyond (extracellular).
[^pre-syn]: **syn- / sym- (before b, p, m)** — together, with: sympathetic, synapse, syndrome, symphysis. Don't confuse with **semi-** half · **sin-** (Latin *sinister*, left).
[^pre-para]: **para-** — beside, alongside, abnormal: parasympathetic, parameter, paracrine, paraesthesia. Don't confuse with **peri-** around (pericardium) · **pre-** before.
[^pre-hyper]: **hyper-** — over, above, excessive: hypertension, hyperpnoea, hyperthermia. Don't confuse with **hypo-** under, deficient · **supra- / super-** above (Latin equivalents).
[^pre-hypo]: **hypo-** — under, below, deficient: hypothalamus (below the thalamus), hypotension, hypothermia. Don't confuse with **hyper-** over · **hypno-** sleep (hypnotic) · **sub- / infra-** below (Latin equivalents).
[^suf-ation]: **-ation / -ition / -ion** — the process or result of an action: coagulation, parturition, regulation, correction. Don't confuse with **-osis** a condition or state (thrombosis) · **-ism** a state or doctrine (metabolism).
[^suf-rrhage]: **-rrhage / -rrhagia** — bursting forth, heavy bleeding: haemorrhage, menorrhagia. Don't confuse with **-rrhoea** flow, discharge (diarrhoea) · **-rrhaphy** suturing (herniorrhaphy) · **-rrhexis** rupture (karyorrhexis).
[^pre-ante]: **ante-** — before: anticipatory (despite the spelling, *anti-cipate* comes from *ante-* + *capere*), antenatal, anterior. Don't confuse with **anti-** against (anticoagulant, antibody) · **post-** after.
[^pre-tachy]: **tachy-** — swift, fast: tachycardia, tachypnoea, tachyarrhythmia. Don't confuse with **brady-** slow · **brachy-** short (brachydactyly).
[^suf-cardia]: **-cardia** — a condition of the heart: tachycardia, bradycardia, dextrocardia. Don't confuse with the noun **cardia** (the part of the stomach next to the heart) · **-cardium** a layer of the heart (pericardium, myocardium).
[^suf-pnoea]: **-pnoea / -pnea** — breathing: tachypnoea, dyspnoea, apnoea, orthopnoea. Don't confuse with **pneumo- / pneumono-** air, lung (pneumothorax, pneumonia).
[^pre-equi]: **equi-** — equal: equilibrium, equivalent, equimolar. Don't confuse with **equine** of a horse (Latin *equus*) · **iso-** equal (Greek synonym: isotonic).
[^suf-ellum]: **-ellum / -ella / -ule / -ole** — small (diminutive): cerebellum (little brain), flagellum, tubule, arteriole. Don't confuse with **-ium** a structure or layer (pericardium) · **-oma** a tumour (lipoma).
