# Homeostasis

## Introduction
- Concept of constancy
  - Central theme for bodily function
  - Disturbance in homeostasis → disease
- Claude Bernard
  - Coined milieu intérieur
  - = internal environment (ECF)
- Walter Cannon
  - Coined homeostasis

## Control systems of homeostasis
### Negative feedback
- ↑ stimulus → ↓ parameter
  - Response opposite to stimulus → stabilises
- Examples
  - Baroreflex → BP ↑ in exercise, ↓ after
  - Endocrine hormone regulation (99 %)
  - Gastric acid secretion
- Components (baroreflex)
  - Stimulus → ↑ BP
  - Receptors → baroreceptors
  - Afferents → to the centre
  - Centre → medulla
  - Efferents → SNS (–), PNS (+)
  - Response → ↓ HR, ↓ BP
- Gain = correction ÷ error remaining
  - Error zero → gain = ∞
  - Kidneys always bring BP back to normal
  - HTN → kidney affected → BP never normal

### Positive feedback
- ↑ initiating stimulus → further ↑ response
  - Amplification / cascade
  - Vicious cycle → destabilises
- CLAPS
  - C → coagulation cascade
  - L → LH surge (only true endocrine +ve feedback)
  - A → action potential
  - P → parturition (Ferguson reflex)
  - S → shock
- Ferguson reflex
  - Fetal head → pressure on cervix
  - → oxytocin release
  - → uterine contraction
  - → head pushed further down → cycle
  - → delivery of fetus
- Shock
  - Haemorrhagic shock (RTA) → irreversible shock → death

### Feedforward
- Anticipatory control system
  - No actual stimulus yet
- Anticipatory tachycardia & tachypnoea
  - ↑ HR, ↑ RR before exercise
- Anticipatory motor control
  - Centre → cerebellum
  - Braking on seeing a cow on the highway
- Anticipatory core-temperature regulation
  - Shell = skin temperature
  - Core = organ temperature
  - Cold → ↓ shell → hypothalamus anticipates ↓ core
  - → corrective measures → core maintained

## Properties of homeostasis
### Dynamic constancy
- AKA dynamic equilibrium
- Maintains a range of values, not a point
  - Tolerance range between upper and lower limits
  - HR 60–100 bpm
  - RR 12–18 /min

### Prioritization of parameters
- pH > BP > temperature
- pH first → affects enzyme activity → death
