# Cardiac Action Potentials

## SA nodal & ventricular action potential
### Comparison
- RMP
  - SA node → restless membrane potential −60 to −40 mV
  - Ventricle → resting membrane potential −90 mV
- Property
  - SA node → chronotropy (heart rate generation)
  - Ventricle → inotropy (contractility)

### SA nodal potential
- Phase 4 → prepotential (−60 → −40 mV)
  - Transient Ca²⁺ channel (Ca²⁺T) → influx
  - Funny current (Na⁺f) → influx
  - ↓ K⁺ efflux
- Phase 0 → depolarisation
  - Ca²⁺L → long lasting Ca²⁺ channel
- Phase 3 → repolarisation
  - K⁺ efflux
- No phase 1, no phase 2 → no plateau

### Ventricular action potential
- Phase 0 → early depolarisation → Na⁺ influx
- Phase 1 → early repolarisation → K⁺T transient K⁺ channel
- Phase 2 → plateau → Ca²⁺L in, K⁺ out
- Phase 3 → late / proper repolarisation → K⁺DR delayed rectifier
- Phase 4 → resting membrane potential −90 mV → Na⁺–K⁺ pump

### Funny current / HCN channels
- Location → eye, heart (SA node)
- Opened by → cyclic GMP (page)
- Function → vision, heart rate generation
- Applied → ivabradine = funny current blocker
  - Used in Rx of arrhythmia
  - S/E → ↓ visual acuity

### Effect of ANS on prepotential
- Sympathetic (+) → steeper slope → ↑HR (+ chronotropy)
- Parasympathetic (−) → flatter slope → ↓HR (− chronotropic)

## Conduction system of heart
- Dromotropy = conduction of impulses
- Impulse time SA node → Purkinje = 0.22 s

### SA node
- Dominant pacemaker
- Impulse 100/min → highest rate
  - Resting vagal tone (−) → HR 72/min
  - Atropine (PNS blocker) (+) → HR 150 bpm
  - Heart transplant (denervated) → no effect → HR 100 bpm
- Overdrive suppression → suppresses other pacemakers

### AV node
- Gatekeeper of heart
- Physiological delay 0.1 s
  - For adequate ventricular relaxation (filling)
- Conduction velocity 0.04 m/s → slowest
  - D/t ↓ gap junctions

### Bundle of His
- Carries the impulse from AV node into the septum

### Purkinje fibres
- Innervate every single ventricular myocardial cell
  - Functional syncytium → synchronised contractions
- Conduction velocity 4 m/s → highest
  - D/t ↑ gap junctions at intercalated disc
