# Classification of Nerve Fibres

## Classification of nerve fibers
### Types
- Erlanger–Gasser classification
- Lloyd–Hunt classification

### Erlanger–Gasser classification
- Erlanger and Gasser → Nobel Prize
- Based on myelin
  - Present → A, B
    - A → α, β, γ, δ
  - Absent → C
- Diameter → largest (Aα) → smallest (C)
- Conduction velocity → max 120 m/s → min 2 m/s
- Spike duration → least (Aα) → most (C)

### Functions of nerve fibers
- Sensory (S), motor (M) or both
- Aα
  - S → proprioception (joint position sense)
  - M → alpha motor neuron (spinal cord)
- Aβ → S → touch
- Aγ → M → muscle spindle (gamma motor neuron, regulates tone)
- Aδ → S → fast pain (1st pain)
- B → preganglionic autonomic fibres
- C
  - S → slow pain (2nd pain)
  - Postganglionic autonomic fibres

### Susceptibility
- Compression → Aα (largest) > Aβ
- Hypoxia
  - Most → B
  - Least → C

### Lloyd–Hunt classification
- AKA sensory classification
- Only for sensory fibres
- Numerical classification
  - I → Ia muscle spindles, Ib Golgi tendon organ → Aα
  - II → Aβ
  - III → Aδ
  - IV → C

## Action potential
### Characteristics
- Response needs a stimulus of particular strength and duration

### Strength–duration curve
- Rheobase → minimum strength of current for a response
- Chronaxie → minimum time for a response at twice rheobase
- Importance → chronaxie ∝ 1/excitability
- Nerve → chronaxie ↓, excitability ↑
- Muscle → chronaxie ↑, excitability ↓

### Response on repeated stimulus
- Subthreshold → accommodation → no AP
- Threshold stimulus → AP
- Suprathreshold → adaptation → no AP

## Nerve injury
### General
- m/c cause → bone fractures
- m/c part susceptible → axon
- Based on nature → degeneration, regeneration

### Degeneration
- Distal degeneration
  - AKA Wallerian degeneration
  - Earliest → within 24 hours
  - Axonal degeneration
  - Myelin degeneration
  - Phagocytosis of debris → clears site of injury
- Proximal degeneration
  - 36 hours after injury
  - Nucleus → pushed to periphery
  - Nissl body → chromatolysis (broken down)

### Regeneration
- 90 hours after injury
- Slow → 1–3 mm/day
- Tinel sign
  - Procedure → tapping at site of injured nerve
  - Inference → tingling (electric-shock type) → good prognosis

### Encapsulating structures
- Epineurium → outermost layer
- Perineurium → encloses bundles
- Endoneurium → encloses axons

### Classification of nerve injury
- Purpose → assess prognosis and plan treatment
- Seddon's classification
  - Neuropraxia
    - Compression, intact nerve
    - Local conduction block
    - Eg → Saturday night palsy
    - Spontaneous recovery → good prognosis
  - Axonotmesis
    - Axonal injury → Wallerian degeneration
    - Regeneration 1–3 mm/day
    - Recovery possible → intermediate prognosis
  - Neurotmesis
    - Complete transection → worst prognosis
- Sunderland classification
  - I → neuropraxia
  - II → axonotmesis
  - III → axonotmesis + endoneurium disrupted
  - IV → axonotmesis + endoneurium + perineurium disrupted
  - V → neurotmesis (all sheaths) → worst prognosis
  - Grade IV & V → surgical intervention
