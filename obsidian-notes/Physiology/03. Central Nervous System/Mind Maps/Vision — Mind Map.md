# Vision

## Organisation of vision
- Vision is a special sense
- 3 levels → retina → thalamus → occipital visual cortex
- General senses → 4 levels (include spinal cord)

## Retina
- 7 types of cells
  - 1st–6th → role in vision
  - 7th → supporting cell
### Retinal cells
- Rods → rod shaped
- Cones → cone shaped
- Bipolar cell → 2 poles
  - One pole receives information
  - One pole conducts information
- Ganglion cells (GC)
  - Only retinal cell with an output → axons → optic nerve → thalamus
  - Only retinal cell to generate action potential → long distances
- Horizontal cell → connects cones & rods
- Amacrine cell → connects bipolar cell to ganglion cells
- Müller's cell → retinal glial cell, supportive function

### Photoreceptors
- Rods
  - Dim light → night vision
  - 100 million
  - Rhodopsin / visual purple
  - Peripheral retina
- Cones
  - Colour vision → day vision
  - 5 million
  - Iodopsin
  - Central retina
  - Foveola → only cones (rod-free zone)

### Lateral inhibition
- Horizontal / amacrine cell → inhibits lateral cells
- → enhanced output from central cell
- → ↑ contrast & sharpness

### Melanopsin ganglion cells
- Directly stimulated by light
- Pigment → melanopsin
- Contain PACAP → signalling
- Projection 1 → retinal hypothalamic tract
  - → suprachiasmatic nucleus → 24 h circadian rhythm
- Projection 2 → pretectal nucleus
  - → Edinger-Westphal nucleus → pupillary light reflex

### Phototransduction
- Changes in retina when light strikes it
- Rhodopsin → opsin + vitamin A
- Forms of vitamin A
  - 11-cis retinal → dark state
  - All-trans retinal → light state
- Dark state
  - RMP of rods −60 mV (passive K⁺ diffusion)
  - Funny current channel open → Na⁺ influx
  - → depolarization → glutamate release
- Light state
  - 11-cis → light → all-trans retinal
  - → transducin (+) → phosphodiesterase (+)
  - → degrades cGMP → funny Na⁺ channel closes
  - K⁺ channels open → K⁺ efflux → hyperpolarisation
  - → ↓ glutamate release
- Wald's visual cycle
  - Constant cycling of 2 forms of vitamin A, day & night
  - 11-cis (dark) ⇄ all-trans (light)
- Funny current / HCN channels
  - Na⁺ channels, opened by cGMP
  - Retina → vision
  - SA node → generation of HR
- Amacrine cells
  - Purely depolarizing (no hyperpolarisation)
  - Role in lateral inhibition
  - Neurotransmitter → acetylcholine

## Visual pathway
- Temporal and nasal fields of each eye
- Optic nerve → I/L nasal & temporal fibres
- Optic chiasma → nasal fibres cross
- Optic tract → I/L temporal & C/L nasal fibres
- Thalamic nucleus → lateral geniculate body (LGB)
- Optic radiation → visual cortex
- Visual defect depends on location of lesion

## Thalamus
### Lateral geniculate body
- 6 layers
- Magnocellular pathway (M cells, big)
  - Origin → layers 1, 2
  - Ends → layer 4 of visual cortex
  - Extraocular movements, detection of flickering
- Parvocellular pathway (P cells, small)
  - Origin → layers 3, 4, 5, 6
  - Ends → layer 4 of visual cortex
  - Colour vision, finer details in visual field
- Koniocellular pathway (K cells)
  - Origin → between P & M cells
  - Colour vision → blue
### Inputs to LGB
- I/L LGB receives I/L & C/L eye
- Layers 1, 4, 6 → C/L fibres
- Layers 2, 3, 5 → I/L fibres

## Visual cortex
### Location
- Calcarine cortex (occipital lobe) → Brodmann 17, 18, 19
- Heavily myelinated
- Striae of Gennari → AKA striate cortex
### Cells
- Simple & complex cells
  - Higher order processing
  - Feature detectors → detect minute changes
- Blobs
  - Colour vision
  - Express cytochrome oxidase
### Extrastriate cortices
- Parietal lobe
  - From magnocellular pathway
  - Eyeball movements
- Temporal lobe
  - From parvocellular pathway
  - Colour vision
### Inferior temporal cortex
- Face recognition by sight
- Lesion → prosopagnosia → loss of face recognition

## Colour vision
### Pathway
- Retina → cones
- Thalamus → parvocellular pathway
- Visual cortex → blobs
- Test → Ishihara chart
### Cones
- Primary colours → red, blue, green
- L cone → long wavelength → red
- M cone → medium wavelength → green
- S cone → small (short) wavelength → blue
### Colour blindness
- X-linked recessive disorders
- Males > females (carriers)
- Most common → red–green defect
- Red defect → protanopia
- Green defect → deuteranopia
- Blue defect → tritanopia

## Order of neurons & light reflex
### Order of neurons
- 1st order → photoreceptors (cone, rod)
- 2nd order → bipolar cell
- 3rd order → ganglion cell → optic nerve → chiasma
- 4th order → lateral geniculate body → optic radiation → visual cortex
### Light reflex
- Afferent → optic nerve
- Pretectal nucleus → fibres cross over
- Centre → Edinger-Westphal nucleus
- Efferent → oculomotor nerve
- Ciliary ganglion → sphincter pupillae → pupils constrict
- Lit eye → direct light reflex
- Other eye → indirect light reflex
