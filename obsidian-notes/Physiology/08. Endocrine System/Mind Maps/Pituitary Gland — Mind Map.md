# Pituitary Gland

## Pituitary Gland — Overview
### Parts
- Hypothalamus → infundibulum (stalk) → pituitary gland
- Anterior pituitary
  - = adenohypophysis = master gland
  - Capillary plexus (portal supply)
- Posterior pituitary
  - = neurohypophysis
  - Hypothalamohypophyseal tract ends here

### Posterior pituitary
- No synthesis
- Only storage (Herring bodies) & release
  - ADH / vasopressin
  - Oxytocin

## Anterior Pituitary & Hypothalamus
### Acidophilic cells
- Somatotrophs (50 % of cells) → growth hormone
- Lactotrophs → prolactin
- GH + prolactin = "twin hormones"
  - Similar receptors & actions

### Basophilic cells
- Thyrotrophs → TSH
- Gonadotrophs → LH, FSH
- Corticotrophs → POMC (pro-opio-melanocortin)

### Negative feedback system
- Hypothalamus → releasing hormone (TRH)
- → (+) anterior pituitary → trophic hormone (TSH)
- → (+) target gland (thyroid) → peripheral hormones (T3, T4)
- T3, T4 → (−) anterior pituitary and hypothalamus

### POMC products
- Opio → endorphin
- Melano → MSH
- Cortin → ACTH
- Applied: Addison's disease
  - Pathologically ↑↑↑ ACTH → MSH action
  - → skin hyperpigmentation

### Hypothalamic releasing hormones
- TRH → TSH, prolactin
- CRH → ACTH
- GnRH → LH, FSH
- GHRH → GH

### Hypothalamic inhibiting hormones
- PIH / dopamine → inhibits prolactin release
- GHIH / somatostatin → inhibits GH release

## Anterior Pituitary Hormones
### Growth hormone — levels
- Maximum at adolescence
- Minimum at senescence (old age)

### GH regulation
- Hypothalamus → GHRH (+) → somatotrophs
- Hypothalamus → somatostatin (−) → somatotrophs
- Ghrelin (+) → somatotrophs
- GH → direct actions
- GH → liver → IGF-1 (somatomedin C) → indirect actions
- IGF-1 → feedback to hypothalamus, (−) somatotrophs
- Drug forms
  - GHRH → sermorelin (↑ GH) → Rx pituitary dwarfism
  - Somatostatin → octreotide (− GH) → Rx acromegaly

### Factors affecting GH secretion
- ↑ GH
  - Hypoglycemia → GH → ↑ glucose (diabetogenic)
  - Fasting, starvation, exercise, stress
  - Deep sleep (NREM III & IV)
- ↓ GH
  - Hyperglycemia
  - Somatostatin
  - IGF-1
  - REM sleep

### GH actions
- GH → cytokine receptor → Janus kinase → JAK–STAT
- Direct (by GH) → anti-insulin like
  - Lipolysis
  - Bone growth: prechondrocytes → chondrocytes
- Indirect (by IGF-1) → insulin like
  - Bone growth: all remaining actions at bone

### GH disorders
- Children
  - ↑ GH → gigantism
  - ↓ GH → dwarfism
- Adults → acromegaly
  - d/t GH-releasing pituitary micro-adenoma

### Acromegaly features
- Bony overgrowth → frontal bossing
- ↑ hand + foot size
- Prognathism → mandibular enlargement
- ↑ heel pad thickness (soft tissue overgrowth)
- Carpal tunnel syndrome
- Sleep apnea (upper airway obstruction)
- Diabetes mellitus

### Acromegaly treatment
- Surgical → trans-sphenoidal resection of microadenoma
- Pharmacological
  - Somatostatin analogue → octreotide
  - GH receptor antagonist → pegvisomant

### Laron dwarfism
- = GH insensitivity syndrome
- Etiology → defective receptors
- Levels → N / ↑↑ GH, ↓ IGF-1
- Rx → mecasermin (recombinant IGF-1)

### Recombinant human GH uses
- Rx of dwarfism
- Muscle wasting in AIDS (↑ lean body & muscle mass)
- Anti-aging Rx

### Prolactin — regulation
- Stimulates milk production
- (+) TRH, VIP
- (−) Dopamine (prolactin inhibiting factor)
- (−) Glucocorticoids, thyroid hormones
- Applied: stalk effect
  - Lesion at pituitary stalk
  - → loss of releasing & inhibitory factors
  - → ↑ prolactin (↓ dopamine), all other hormones ↓

### Factors affecting prolactin secretion
- ↑ Secretion
  - Pregnancy & lactation
  - Sexual intercourse
  - Suckling of nipples
  - REM sleep
- ↓ Secretion
  - Dopamine
  - L-dopa
  - Bromocriptine

### Prolactin actions
- Cytokine receptor → Janus kinase → JAK–STAT
- Proliferation of lobulo-alveolar epithelium → milk
- Negative regulator of reproduction
  - Inhibits GnRH → inhibits FSH & LH
  - ♀ → lactational amenorrhea (contraception)
  - ♂ → loss of libido, ↓ spermatogenesis
