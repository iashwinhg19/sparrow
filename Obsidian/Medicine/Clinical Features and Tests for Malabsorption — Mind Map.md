# Clinical Features and Tests for Malabsorption

## Clinical features
### Steps for evaluation
- Confirm the diagnosis → clinically; by investigations
- Confirm global vs selective malabsorption
- Confirm the etiology
### Gastrointestinal
- Osmotic diarrhoea → small intestine; > 4 weeks; ↑ osmotic gap; improves on fasting; most consistent symptom
- Fat malabsorption → steatorrhea
- Carbohydrate malabsorption → bloating, dyspeptic symptoms
- Protein malabsorption → foul smelling stools, ascites, edema
- Unexplained weight loss
### Musculoskeletal
- Fat malabsorption → impaired vitamin D and Ca2+ → tetany, fracture, bone pain
### Cutaneous
- Vitamin B12, niacin → hyperpigmentation
- Vitamin C → perifollicular hemorrhage, curly hair, spiral hair
- Vitamin K → bruisability, ecchymoses
- Zn & essential fatty acids → acrodermatitis
- Vitamin A → follicular hyperkeratosis
### Miscellaneous
- Coeliac disease → growth retardation
- Anaemia
  - Distal pathology → vitamin B12 deficiency
  - Proximal pathology → folate / iron deficiency
- Vitamin B12/E → peripheral neuropathy, ataxia
- Vitamin B12 → glossitis, cheilosis, stomatitis
- Vitamin A → night blindness, xerophthalmia
- Kidney stones
  - Normal → oxalate + Ca2+ → excreted
  - Malabsorption → fatty acid + Ca2+ → free oxalate → absorbed in colon → oxaluria → Ca-oxalate stones
### Notes
- Not seen in malabsorption → abdominal pain, constipation, fever
- Differentials → TB (weight loss, long-standing diarrhoea, edema/ascites); nephrotic syndrome (protein loss)

## Investigations
### Fat malabsorption
- Qualitative → Sudan III
- Quantitative (gold standard) → fecal fat excretion ≥ 7 g/day
- Fecal fat excretion test → gold standard investigation for malabsorption
### D-xylose test
- Best and most specific test
- Pentose monosaccharide
- Assesses intact small intestinal mucosa
- Procedure
  - 25 g D-xylose orally after fasting (early morning)
  - Collect entire urine after 4–6 h → check D-xylose
  - > 4.5 g → normal
  - < 4.5 g → positive → small intestinal mucosal pathology
- False positives (etiology not in small intestine)
  - Renal failure → defective excretion
  - Rapid transit (hyperthyroidism, vomiting) → reduced time for absorption
  - SIBO → organisms utilise D-xylose
  - Ascites → sequestration into third space
### Lactose tolerance test
- Obsolete
### Lactose H2 breath test
- For lactase deficiency
- Lactase deficiency → lactose accumulates in large intestine → bacterial action → H2
- Diagnosis → breath H2 > 20 ppm
### Lactulose H2 breath test
- Metabolised in large intestine → H2
- H2 within 90 min (early peak) → SIBO
- H2 > 90 min → normal
### Obsolete tests
- Acid steatocrit → fat malabsorption
- C-14 triolein breath test → fat malabsorption
- C-13 egg white breath test (phenol, p-cresol in urine) → protein malabsorption
### Other markers
- Stool elastase, chymotrypsin → pancreatic insufficiency
- Fecal α-1 antitrypsin → primary intestinal lymphangiectasia
- NIRA (near infrared reflectance analysis) → newer test
- Diagnosed on biopsy → Whipple's disease; agammaglobulinemia; abetalipoproteinemia
### Schilling test
- Phase I
  - 1000 µg unlabelled vitamin B12 IM → saturate stores
  - 1 µg oral radiolabelled vitamin B12
  - Urine B12 < 7 % → positive (malabsorption)
  - Urine B12 7–10 % → normal
- Phase II
  - Intrinsic factor → > 10 % → pernicious anemia
  - Antibiotics → > 10 % → SIBO
  - Pancreatic enzymes → > 10 % → chronic pancreatitis
- After phase I & II, urine B12 < 7 % → ileal disease
