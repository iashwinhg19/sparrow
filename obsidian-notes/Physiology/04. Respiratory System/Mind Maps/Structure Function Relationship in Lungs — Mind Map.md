# Structure Function Relationship in Lungs

## Conducting Airways
### Epithelium
- Weibel model of airway
  - 23 airway generations
- Conducting zone → generations 0–16
  - Trachea (0) → dead space, no gas exchange
  - Bronchi → bronchioles → terminal bronchioles (16)
  - Medium sized bronchi → max resistance to airflow
- Transitional and respiratory zones → generations 17–23
  - Respiratory bronchioles (17–19)
  - Alveolar ducts (20–22)
  - Alveolar sacs (23)
  - Gas exchange occurs
- Pseudostratified columnar epithelium
  - Stem cells → basal cell, Clara cell (club cell)
  - Mucus moves towards nasopharynx
- Ciliary movement
  - Driven by protein → dynein
  - Synchronized movement → metachronism
  - Function → clearing sputum
### Immotile cilia syndromes
- Cystic fibrosis
  - CFTR gene mutation
  - → defective Cl⁻ opening
  - → thick sputum
  - Rx → ivacaftor → opens Cl⁻ channel
- Kartagener syndrome
  - Pathophysiology → absent dynein
  - Bronchiectasis
  - Sinusitis
  - Situs inversus → dextrocardia
  - Plus asthenospermia → immotile sperm
- Note on cilia
  - Rotation of internal organs during development
- Dynein moves
  - Cilia
  - Sperm
  - Fallopian tube
### Smooth muscles
- Bronchoconstriction
  - Resistance ↑, airflow ↓
  - Parasympathetic
  - Leukotriene (most potent)
  - Acetylcholine
  - Histamine
  - Exaggerated → asthma
- Bronchodilation
  - Resistance ↓, airflow ↑
  - Sympathetic → β2 receptor
  - Salbutamol (β2 agonist)
  - Nitric oxide
  - Prostaglandin
  - β2 agonists → Rx of asthma

## Alveolar Airways
### Alveoli
- Terminal bronchiole → respiratory bronchiole
- → alveolar duct → alveolar sac
- Capillaries over each alveolus
  - Deoxygenated blood from pulmonary artery
  - Oxygenated blood to pulmonary vein
### Pneumocytes
- Type I
  - Large, flat
  - ↑ surface area
  - ↓ in number
- Type 2
  - Small
  - ↓ surface area
  - ↑ in number
  - Function → surfactant production
  - Function → transforms into stem cell for regeneration
- Stem cells in airway
  - Basal cell
  - Clara cell (club cell)
  - Type 2 pneumocyte
### Surfactant
- Production
  - Type 2 pneumocyte
  - Lamellar bodies → store surfactant
  - Appears around 28–32 weeks of gestation
- Composition → lipoprotein complex
  - Lipids → lecithin (major) = DPPC
  - Lipids → sphingomyelin (minor)
  - Proteins → surfactant proteins A, B, C, D
  - A and D → role in lung immunity
- Function 1 → fetal lung maturity tests
  - Lamellar body counting
  - L/S ratio ≥ 2 → mature fetal lungs
  - Shake test / bubble test / Clements test
  - Bubbles on shaking amniotic fluid → surfactant +
- Function 2 → prevent alveolar collapse
  - Laplace law → P = 2T/r
  - Without surfactant → T ↑, r ↓, area ↓, P ↑ → collapse
  - With surfactant → T ↓, r ↑, area ↑, P ↓ → no collapse
### Applied aspect — RDS
- Respiratory distress syndrome
  - AKA hyaline membrane disease (HMD)
  - Surfactant deficiency → alveoli collapse
- Rx → surfactant drugs
  - Beractant
  - Lucinactant
- Histopathology
  - Collapsed alveoli beside normal alveoli
### Regulation of surfactant production
- Stimulating (physiological)
  - Steroid → cortisol
    - Used in preterm babies for lung maturation
    - Betamethasone, dexamethasone
  - Thyroid hormones → T3, T4
- Inhibiting (pathological)
  - High insulin → inhibits cortisol
    - Infants of diabetic mothers → surfactant deficiency → RDS
  - Cigarette smoking
  - O₂ toxicity
  - Occlusion of main bronchus
  - Occlusion of one pulmonary artery
